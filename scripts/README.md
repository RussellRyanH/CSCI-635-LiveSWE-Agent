# Scripts
As part of our artifact improvements, we created a few scripts to facilitate replicating both our work and that of the original paper. Below we have provided a description of each scirpt and how to use them:

- get_model_stats.py - This script aggregates all of the statistics from the trajectories for a run of a subset of problems, and places them in a .csv file in the output directory. Usage -> `python get_model_stats.py <PATH_TO_RUN_OUTPUT_DIR>`

- remove_error_problems.py -  When running large subsets, it was common to encouter errors such as RateLimitError. Problems that encounter this need to be rerun. mini-swe-agent will pick up from where it left off when you cancel it, so we created a script to scrub all of the files generated by error problems in order to easily rerun them. It removes all RateLimitErrors by default, but other error types can be specified by key. Usage -> `python remove_error_problems.py <results_directory> <exit_status.yaml> <OPTIONAL: error_key_to_remove>`
