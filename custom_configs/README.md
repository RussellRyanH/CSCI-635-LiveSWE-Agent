# Confirguation Files
This folder contains the custom mini-swe-agent configuration files used to implement the different versions of live-swe-agent for our experiments on the SWE-bench Verified. Before using these configs, ensure that the model and environmental parameters in the bottom of the file are set correctly for your specific scenario.

## Warning
These files align with the naming and structure of mini-swe-agent V1. 
Attempts to use them with mini-swe-agent V2 will produce erroneous results!
